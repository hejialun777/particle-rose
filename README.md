# 粒子玫瑰花束 · Particle Rose

用纯 Canvas 2D 手写的 3D 软渲染，把一束玫瑰画成几万颗发光粒子。

**没有任何第三方依赖**——不用 Three.js，不用 Python，不用联网。双击 HTML 文件就能在浏览器里跑，整个项目就是两个自包含的单文件。

## 两个版本

| 文件 | 效果 |
|---|---|
| `rose.html` | **静态粒子版**。粒子位置固定，轮廓清晰；每朵玫瑰绕自己的花轴自转；开场是一朵一朵依次绽放 |
| `heart.html` | **漂浮粒子版**。每颗粒子被目标位置拉住、同时不断被随机轻推，整束花始终在轻微浮动，边缘毛茸茸的；开场就成形，不做飞入动画 |

两个文件各自独立，改一个不影响另一个。

## 运行

双击任意一个 `.html` 文件，用 Chrome / Edge 打开即可。不需要装任何东西，不需要本地服务器。

- **按住鼠标拖动**可以手动旋转着看
- 不操作时会自动缓慢旋转

## 画面里有什么

一束共 33 朵玫瑰，分成四圈：

- 1 朵居中（最高最大）
- 6 朵中圈
- 12 朵外圈
- 14 朵最下一圈，几乎平躺着朝外开

外加：弯曲收拢的花茎、握把、每根茎上两片绿叶、一层内衬棉纸、五张围成一圈的包装纸，以及绑在花茎交界处的白色飘带（缎带圈 + 结心 + 两条会摆动的飘带）。

## 怎么实现的

整个渲染是手写的，核心就三步：

**1. 把形状拆成参数曲面。** 一朵玫瑰由 6 层花瓣构成，每层是一片参数曲面：花瓣中心线用欧拉积分从根部往外算，越往外越外卷（内层短而直立、外层长而外卷），再沿中心线往两边展开成叶形——根部宽度为 0、中段最宽、瓣尖收成一点，横向还有一层"抱合"弧度和边缘褶皱。在这张曲面上随机撒点，就是花瓣粒子。

**2. 3D 旋转 + 透视投影。** 每帧绕 Y 轴旋转、绕 X 轴俯仰，再用 `k = FOV / (z + CAM)` 做透视（近大远小），最后换算成屏幕坐标。

**3. 加色混合画光点。** 关键就一行 `ctx.globalCompositeOperation = 'lighter'`。每颗粒子画成一张预渲染好的径向渐变贴图，重叠的地方亮度自动叠加、自然发白，光晕感就是这么来的。好处是**不需要按深度排序**，几万颗点可以直接顺序画。

粒子尺寸和密度都跟着花束整体大小自动缩放，所以增删花朵、改纸张规格，屏幕上的颗粒感都不会变。

## 可以调的地方

两个文件的顶部都集中放了一组常量：

| 常量 | 作用 |
|---|---|
| `SATURATION` | 玫瑰饱和度，`1` = 鲜艳，`0` = 全灰 |
| `GREEN_SAT` | 茎叶的饱和度 |
| `AUTO_SPIN` | 自动旋转速度 |
| `DENSITY` | （`heart.html`）全局粒子密度倍数 |
| `JITTER_FRAC` | （`heart.html`）粒子抖动幅度，决定"毛茸茸"的程度 |
| `SHAPE` | （`heart.html`）切换形状：`bouquet` 花束 / `rose` 单朵 / `heart` 心形 |

包装纸是按真实花艺规格做的，尺寸用厘米标定（单朵玫瑰头直径按 9.5cm 换算）：

| 常量 | 规格 |
|---|---|
| `WRAP_SPAN` | 每张纸覆盖的圆心角，90° ≈ 1/4 圈 |
| `WRAP_N` | 围一圈用几张纸 |
| `WRAP_STEP_CM` | 相邻两张纸的层高差（cm），外层略高于内层 |
| `WRAP_TOP_CM` | 最高的尖顶比花头低多少（cm） |
| `WRAP_TIP_CM` | 单个尖角的高度（cm） |
| `WRAP_ANGLE` | 尖角角度（度），要求 ≤ 60° |

## 性能

`heart.html` 每颗粒子每帧都要算弹簧，比 `rose.html` 费 CPU。两个文件都内置了帧率兜底：掉到 30fps 以下会自动少画一部分粒子，回到 60fps 再补回来。

如果觉得卡，调小 `DENSITY`（`heart.html`）或花束那段的粒子数系数（`rose.html`）。
